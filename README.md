# Captain Z — A Digital World in Flight

Static personal portfolio for Yahya Zakaria.

No npm, Node.js, framework, backend, or database required.

## Local preview
Because the site uses `fetch()` for `About/About.txt` and `src/project.json`, preview it through a local static server such as VS Code Live Server or another static HTTP server. Opening `index.html` directly with `file://` may block those fetch requests in some browsers.

## Profile photo
Replace `image/profile.jpg` with the real profile photo. The current file is a neutral local placeholder so the package remains visually complete.

## Contact links
The contact buttons in `contact.html` are intentionally generic placeholders (`wa.me`, `instagram.com`, `github.com`). Replace them with the actual public profile links before publishing.
